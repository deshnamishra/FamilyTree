# FamilyTree

An interactive full-stack Family Tree Management System built with React, Node.js, Express, and MongoDB. The application allows users to create, manage, and visualize family relationships through an intuitive tree interface.

---

##  Features

- Create and manage multiple family trees
- Add, edit, and delete family members
- Define parent-child relationships
- Interactive tree visualization
- Responsive design for desktop and mobile
- RESTful API architecture
- MongoDB Atlas cloud database integration
- Secure backend with Helmet and Rate Limiting
- Production deployment using Vercel and Render

---

## Tech Stack

### Frontend
- React.js
- Axios
- CSS3
- Vercel

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Helmet
- Express Rate Limit
- CORS

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
